📝 Ví Dụ Hiển Thị Đề Thi (Cấu trúc Ex\_test)

Phần này minh họa cách hiển thị cấu trúc `ex_test` trực tiếp từ code HTML. Bạn có thể dán nội dung LaTeX của mình vào khung bên dưới.

\textbf{PHẦN I. Câu trắc nghiệm nhiều phương án lựa chọn}\setcounter{ex}{0}} \begin{ex} Nghiệm của phương trình $\sin x = \dfrac{\sqrt{3}}{2}$ là \choice {\True $x = \dfrac{\pi}{3} + k2\pi$ hoặc $x = \dfrac{2\pi}{3} + k2\pi \ (k \in \mathbb{Z})$} {$x = \dfrac{\pi}{6} + k\pi \ (k \in \mathbb{Z})$} {$x = \dfrac{\pi}{3} + k\pi \ (k \in \mathbb{Z})$} {$x = k\pi \ (k \in \mathbb{Z})$} \loigiai{Ta có $\sin x = \dfrac{\sqrt{3}}{2} = \sin\left(\dfrac{\pi}{3}\right)$. Do đó $x = \dfrac{\pi}{3} + k2\pi$ hoặc $x = \pi - \dfrac{\pi}{3} + k2\pi$. \textbf{Đáp án: A}} \end{ex} \begin{ex} Công thức nào sau đây là công thức nghiệm tổng quát của phương trình $\cos x = \cos \alpha$? \choice {$\hoac{&x = \alpha + k\pi \\ &x = -\alpha + k\pi}$} {\True $\hoac{&x = \alpha + k2\pi \\ &x = -\alpha + k2\pi}$} {$x = \alpha + k\pi$} {$x = \pm \alpha + k\pi$} \loigiai{Đây là công thức nghiệm cơ bản của phương trình cosin. Đáp án B} \end{ex} \textbf{PHẦN II. Câu trắc nghiệm đúng sai}\setcounter{ex}{0}} \begin{ex} Cho cấp số cộng $(u_n)$ có $u_1 = 2$ và công sai $d = 3$. \choiceTF {\True Số hạng tổng quát là $u_n = 3n - 1$} {Số hạng thứ 4 là $10$} {\True $u_5 = 14$} {$S_{3} = 15$} \loigiai{Ta có $u_n = u_1 + (n-1)d = 2 + 3(n-1) = 3n - 1$. $u_4 = 3(4) - 1 = 11$. $u_5 = 3(5)-1 = 14$. $S_3 = \dfrac{3(u_1 + u_3)}{2} = \dfrac{3(2+8)}{2} = 15$. Đáp án Đúng/Sai/Đúng/Đúng.} \end{ex}
